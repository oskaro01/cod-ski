# Optional research tools

These are independent, optional prompts extracted from the supplied working notes. Run only the tool needed for the current question. The core workflow uses Individual Prompt 2 v1.2; these tools support its current methodology.

| Need | File | Result |
|---|---|---|
| Broader category, problem, search or creator evidence | `UGC-Search-and-Demand-Validation.md` | Focused evidence supplement |
| Unresolved questions after Individual Prompt 2 | `Evidence-Gap-Closure.md` | Changes, unresolved dependencies and next-stage readiness |
| A plain-language explanation of the current decision | `Product-Decision-Summary.md` | Decision, promising evidence, risks and next actions |
| A compact spreadsheet Notes cell | `Standardized-Notes.md` | Copy-ready Notes text; optional existing-row update |

Typical use:

```text
Individual Prompt 2
 > optional gap closure (only when decision-changing gaps remain)
 > optional decision summary OR Notes formatting
 > Stage 3 when the existing SAMPLE and entry requirements pass

Demand supplement > evidence input to gap closure or later research
```

Do not automatically run all four tools. The demand supplement can also support an earlier research stage; it does not award a screening YES or replace that stage's evidence requirements.

## How to run

Paste the chosen prompt in the research conversation. Identify the Product ID, exact variant and target country; reuse records actually available there. In another conversation, supply the relevant source records and latest decision. IDs alone cannot recover missing research.

Carry forward original/current product URLs, source references, dates and historical decisions. Each tool returns a bounded output and a checkpoint if unfinished. A checkpoint must contain the completed findings, not only an instruction to remember them.

## Current methodology

Individual Prompt 2 v1.2 uses 60/20/20 GCC marketplace/search/social weights. Missing search/local-social data permits a PROVISIONAL demand score with explicit 60%/80% demand coverage when marketplace evidence is adequately assessed. It does not count as zero or establish a fully validated demand case. Global UGC supports creative potential, separately from local demand.

Sample readiness uses the fixed 15-item core checklist, 80% core minimum and explicit sample-entry requirements. Supplemental search/local-social gaps stay visible and affect confidence. Commercial weights are demand 20, creative 15, economics 30, competition 10 and supplier/execution 25. Preserve old scores and denominators as historical; report methodology changes separately from new evidence. See the main Prompt 2 for the complete rubric and gates.

The pasted notes are design input, not verified product research. No example certification, price, review count, supplier relationship or screenshot is evidence for a new product.
