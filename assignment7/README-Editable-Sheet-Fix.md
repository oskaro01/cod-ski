# Editable Sheet Fix

The earlier `.xlsx` file used an embedded placeholder drawing. Use this file instead for Google Sheets:

`Cost-Comparison-Spreadsheet-Editable-Google-Sheets.csv`

Why this version is better:

- It is fully editable after import.
- The product image uses a real public Swedish dishcloth product photo.
- The first column uses a Google Sheets `IMAGE()` formula.
- The second column keeps the raw image URL for reference.
- The `Product Page URL` column shows the page where the product image/source was found.

Recommended workflow:

1. Open Google Sheets.
2. Import `Cost-Comparison-Spreadsheet-Editable-Google-Sheets.csv`.
3. Choose "Replace spreadsheet" or "Insert new sheet."
4. Resize the rows and first column if the images appear small.
