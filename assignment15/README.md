# Assignment 15 Submission Guide

## Assignment

Set up unified inbox, configure auto-reply rules for common questions, and create a weekly social media performance report template.

## What To Submit

Submit these two files:

1. `Auto-Reply-Rules.md`
2. `Weekly-Social-Media-Performance-Report-Template.md`

## Simple Explanation

- **Unified inbox:** One Ecommerized inbox where Instagram, Facebook, TikTok, WhatsApp, email, or customer messages can be managed together.
- **Auto-reply rules:** Prewritten responses that send automatically when customers ask common questions like "price?", "where is my order?", "how do I use it?", or "refund?"
- **Weekly performance report template:** A blank weekly report form for tracking reach, engagement, link clicks, inbox questions, top posts, and next-week actions.
