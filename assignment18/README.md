# Assignment 18 Submission Guide

## Assignment

**Technical SEO fixes:** Review the provided Google Search Console exports and prepare fixes for the affected website.

## What To Submit

Submit:

`Technical-SEO-Fixes-Report.md`

This file includes:

- Explanation of what the assignment is asking
- All 11 Google Search Console issue labels
- Affected page trends
- URL pattern diagnosis
- Fix plan for every issue
- Validation checklist
- Screenshot checklist

## Important Note

The report does not claim that live fixes were applied. Live fixes require admin access to the website, theme, Search Console, redirects, robots.txt, and sitemap settings.
