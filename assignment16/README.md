# Assignment 16 Submission Guide

## Assignment

Complete keyword research: 30 keywords mapped to pages, optimize 5 product page titles/descriptions/alt text, and rewrite 3 collection page descriptions for SEO.

## What To Submit

Submit:

```text
assignment16/SEO-Keyword-Research-and-On-Page-Optimization.md
```

## Simple Explanation

- **Keyword research:** Find phrases customers might search, such as `swedish dishcloths for kitchen`.
- **Keyword mapping:** Assign each keyword to one page so Google knows which page should rank.
- **Product page optimization:** Rewrite each product's SEO title, meta description, H1, and image alt text.
- **Collection page description rewrite:** Rewrite category page copy so it includes useful keywords naturally.
