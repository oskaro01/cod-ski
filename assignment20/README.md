# Assignment 20 Submission Guide

## Assignment

Make your store live, connect it with Google Merchant Center, and try to fix Google Merchant issues.

## Main Files

| File | Purpose |
|---|---|
| `Google-Merchant-Live-Store-Step-by-Step.md` | Detailed manual setup instructions |
| `Google-Merchant-Issue-Fix-Report.md` | Main report/template to submit |
| `Product-Feed-Required-Fields.md` | Product feed checklist for fixing Merchant issues |
| `screenshots/README.md` | Screenshot checklist |

## Recommended Submission

Submit:

1. `Google-Merchant-Issue-Fix-Report.md`
2. Screenshots from the `screenshots` checklist
3. `Product-Feed-Required-Fields.md` if your instructor asks for product data proof

## Important Note

The live setup must be done manually inside your store admin and Google Merchant Center account. These files give you the exact process and the report format for submission.
