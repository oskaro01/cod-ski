# Vendor Payout Reconciliation

Use this skill for seller earnings and payout operations.

## Core Concepts

- Order item gross price
- Commission rate
- Commission amount
- Seller earning
- Payment gateway fee
- Shipping fee
- Refund deduction
- Payout hold period
- Settlement batch
- Vendor statement

## Rules

- Reconcile at order_item level for multi-vendor orders.
- Keep payout status separate from order status.
- Adjust payouts for refunds, cancellations, and disputes.
- Generate seller statements monthly or per payout cycle.
