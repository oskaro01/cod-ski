# Ecommerce Conversion Auditor

Use this skill to improve ecommerce sales and user experience.

## Audit Areas

- Homepage clarity
- Category navigation
- Search and filters
- Product page conversion
- Add-to-cart visibility
- Mobile layout
- Cart clarity
- Checkout friction
- Shipping and returns visibility
- Payment trust badges
- Reviews and social proof
- WhatsApp/help access
- Bilingual Arabic/English UX

## Khaleeja Priorities

- Make "verified women-owned GCC brands" obvious.
- Show seller verification near products.
- Show delivery time and shipping fee before checkout.
- Add reviews/testimonials early.
- Make mobile product pages easy to buy from.
- Use gift edits and bundles to increase average order value.

## Output Style

Return prioritized fixes with impact, effort, and expected result.
