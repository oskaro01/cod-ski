# Marketplace Admin Operations

Use this skill for internal marketplace management.

## Admin Dashboard Modules

- Pending vendors
- Approved vendors
- Pending products
- Active products
- Orders
- Shipments
- Payments
- Refunds
- Commissions
- Payouts
- Reviews moderation
- Categories
- Promotions
- Audit logs

## Operational KPIs

- Live products
- Active sellers
- Pending seller applications
- Conversion rate
- Average order value
- Gross merchandise value
- Commission revenue
- Order cancellation rate
- Return/refund rate
- Shipping SLA performance

## Rules

- Keep admin workflows simple for MVP.
- Approvals should be traceable.
- Commission reports should reconcile with payments and seller payouts.
