# Marketplace Finance Unit Economics

Use this skill for marketplace profitability and financial planning.

## Key Metrics

- Gross merchandise value (GMV)
- Net revenue / commission revenue
- Average order value (AOV)
- Payment gateway fee
- Shipping cost and shipping subsidy
- Refund and return cost
- Seller payout
- Contribution margin
- Customer acquisition cost (CAC)
- Repeat purchase rate
- Lifetime value (LTV)

## Khaleeja Rules

- Calculate commission per order item because one order can include multiple vendors.
- Model shipping subsidies separately from product revenue.
- Include payment gateway and BNPL fees in margin calculations.
- Show simple examples in AED.
- Separate buyer-paid shipping from Khaleeja-subsidized shipping.

## Output Style

Use beginner-friendly tables and formulas. Explain what each metric means.
