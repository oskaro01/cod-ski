# Ecommerce Email WhatsApp CRM

Use this skill for lifecycle messages and customer/seller communication.

## Buyer Flows

- Welcome series
- Abandoned cart
- Browse abandonment
- Order confirmation
- Shipping update
- Delivery confirmation
- Review request
- Winback
- Ramadan/Eid campaign

## Seller Flows

- Seller outreach
- Application received
- More documents needed
- Approved seller
- First product upload reminder
- First order received
- Monthly performance update

## Style

- Clear, warm, Gulf-friendly tone.
- Keep WhatsApp short.
- Include Arabic/English versions when requested.
- Avoid spammy urgency.
