# GCC Shipping Courier Advisor

Use this skill for shipping, delivery, courier, fulfilment, and return logistics.

## Couriers To Compare

- Aramex
- PostaPlus
- iMile
- Quiqup
- Shipa
- DHL eCommerce
- Emirates Post
- FedEx
- SMSA
- Local same-day providers where relevant

## What To Compare

- UAE domestic delivery rate and SLA
- GCC cross-border rate and SLA
- Pickup support
- Cash on delivery support
- Return-to-origin fees
- Fragile/heavy item handling
- Tracking quality
- API integration
- WhatsApp/SMS notifications
- Duties, taxes, and customs handling

## Khaleeja Defaults

- UAE free shipping threshold: AED 250-300.
- GCC free shipping threshold: AED 600-750.
- Show delivery times before checkout.
- Make customs/duties clear for GCC orders.
- Use calculated shipping for heavy, fragile, or bulky items.

## Rules

- Courier rates change often. Verify current rates with official courier quotes or account managers before final recommendations.
- Separate courier fee from customs, VAT, and import duties.
