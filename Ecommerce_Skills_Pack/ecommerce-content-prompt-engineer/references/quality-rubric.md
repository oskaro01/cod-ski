# Ecommerce Content and Prompt Quality Rubric

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Objective | Unclear task | General task | Clear business and communication outcome |
| Inputs | Critical inputs absent | Some inputs or vague placeholders | Complete, defined, reusable inputs |
| Audience and channel | Generic | Partially adapted | Precisely adapted to audience, stage, and channel |
| Specificity | Mostly filler | Some concrete value | Distinct product, customer, and use-case relevance |
| Persuasion logic | Random claims | Basic benefit or CTA | Coherent value, proof, objection, and action |
| Accuracy and claims | Invents or overclaims | Some safeguards | Uses verified facts and flags unknowns |
| Voice | Inconsistent or generic | Basic tone direction | Observable, consistent voice behavior |
| Output contract | Unusable or ambiguous | Partly structured | Exact, practical, predictable format |
| Reusability | One-off request | Requires manual rewriting | Portable template with defined variables |
| Final QA | No audit | Generic review request | Task-specific audit and revision step |

## Interpretation

- **17-20:** Submission-ready or production-ready
- **13-16:** Useful but needs targeted revision
- **9-12:** Structurally weak; revise before use
- **0-8:** Rebuild from the brief

## Automatic Revision Triggers

Revise regardless of score when the content:

- Fabricates a fact, review, testimonial, policy, certification, result, or scarcity claim
- Makes a regulated or comparative claim without support
- Omits critical compatibility, safety, return, or use limitations
- Uses placeholders that are undefined
- Produces repetitive variants instead of distinct angles
- Fails the requested count, format, or length constraint
