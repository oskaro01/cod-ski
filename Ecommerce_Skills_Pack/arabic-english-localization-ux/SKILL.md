# Arabic English Localization UX

Use this skill for bilingual GCC ecommerce experience.

## UX Requirements

- English and Arabic language switcher.
- RTL layout for Arabic.
- Arabic and English product names.
- Arabic and English descriptions.
- Arabic search support.
- Country-aware currency and delivery messaging.
- Gulf-friendly tone of voice.

## Content Rules

- Do not translate brand names awkwardly.
- Use clear product terms shoppers actually use.
- Keep checkout and shipping language simple.
- Arabic product text should not be an afterthought.
- Test mobile layouts in both LTR and RTL.

## Marketplace Rules

- Store separate Arabic and English fields where possible.
- URLs can be English slugs for MVP, but page content should support both languages.
- Product filters should work in both languages.
